# Bulut Bilişim Dersi Ödevi ve Projesi

## Proje Adı
Docker Kullanılarak Çalıştırılan Basit Bir Kişisel Web Sayfasının Hazırlanması ve GitHub Üzerinde Yayınlanması

## Öğrenci Bilgileri
* **Adı Soyadı:** Furkan KILIÇ
* **Bölüm / Program:** Bilgisayar Programcılığı Bölümü

## Projenin Kısa Açıklaması
Bu proje, Docker container mantığını anlamak, temel web geliştirme (HTML/CSS) pratiklerini uygulamak ve projeyi GitHub ile entegre bir şekilde canlıya alma adımlarını deneyimlemek amacıyla hazırlanmış temel bir bulut bilişim projesidir.

## Kullanılan Teknolojiler
* HTML5 & CSS3 
* Docker (Containerization)
* Nginx (Web Sunucusu)
* GitHub & GitHub Pages (Versiyon Kontrolü ve Canlı Yayınlama)

## Docker Çalıştırma Komutları
